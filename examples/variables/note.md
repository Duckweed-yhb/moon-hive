# 02 · 变量与绑定

MoonBit 默认不可变——这是它和许多语言的关键区别。

## 代码

```moonbit
fn main {
  let x = 42

  let mut y = 0
  y = x + 8

  println("x = \{x}, y = \{y}")
}
```

## 运行

```bash
moon run main
```

## 输出

```
x = 42, y = 50
```

## 要点

- `let x = 42`：**不可变绑定**。绑定后 x 的值不能再改，试图赋值会编译报错
- `let mut y = 0`：**可变绑定**。加 `mut` 关键字才能重新赋值
- 类型由编译器自动推断（42 是 Int，不用手写类型）
- `\{expr}` 是字符串插值：把表达式的值嵌进字符串，比拼接更直观

## 为什么默认不可变？

少一个"值被悄悄改掉"的可能，就少一类 bug。需要变的时候才显式写 `mut`——代码的意图一目了然。
