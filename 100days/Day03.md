# Day 03 · 基本类型：五种数据，各就各位

> 对应示例：[examples/types](../examples/types/)
> 预计用时：50 分钟

## 今天学什么

程序处理的数据有不同种类：数数用的整数、带小数的浮点、一段文本、一个真假判断、一个单独字符。MoonBit 把这几种数据分成**基本类型**，编译器根据类型决定"这个值能做什么运算"。今天认识这五种类型，以及一个让很多新手困惑的现象：为什么 `3.14` 打印出来是 `3.140000104904175`。

## 一、五种基本类型

打开 [examples/types/main.mbt](../examples/types/main.mbt)：

```moonbit
fn main {
  // Int：32 位有符号整数
  let n: Int = 42

  // Float：64 位双精度浮点
  let pi: Float = 3.14

  // String：文本
  let name: String = "MoonBit"

  // Bool：只有 true / false
  let ok: Bool = true

  // Char：单引号，存一个 Unicode 字符
  let letter: Char = 'M'

  println("n = \{n}")
  println("pi = \{pi}")
  println("name = \{name}")
  println("ok = \{ok}")
  println("letter = \{letter}")
}
```

运行后输出：

```
n = 42
pi = 3.140000104904175
name = MoonBit
ok = true
letter = M
```

五个类型、各自一个字面量：

| 类型 | 例子 | 存什么 |
|---|---|---|
| `Int` | `42` | 整数，32 位 |
| `Float` | `3.14` | 小数，64 位双精度 |
| `String` | `"MoonBit"` | 一段文本，**双引号** |
| `Bool` | `true` | 只有 `true` / `false` 两个值 |
| `Char` | `'M'` | 单个字符，**单引号** |

两个最容易混的地方：字符串用双引号、字符用单引号，写反了编译器直接报错；`Bool` 只有真和假两个值，不存在"半个真"。

## 二、类型标注和类型推断

注意代码里有两种写法：

```moonbit
let n: Int = 42        // 显式标注：冒号后面写类型
let inferred = 2026    // 靠推断：2026 一看就是整数
```

`let n: Int = 42` 里的 `: Int` 是**类型标注**，自己告诉编译器"n 是整数"。`let inferred = 2026` 没写类型，编译器看到字面量 `2026`，自动推断出它是 `Int`。两种写法等价，日常多数时候靠推断就够了，标注适合"想让读代码的人一眼看出类型"的地方。

## 三、为什么 pi 变成了 3.140000104904175

这是今天最值得记住的一行输出。`3.14` 打印出来是 `3.140000104904175`，看起来像 bug，其实是 Float 的正常行为。

计算机用二进制存小数，而 `3.14` 的二进制表示是**无限循环**的，就像 1/3 在十进制里是 0.333… 永远写不完一样。Float 只有 64 位，存不下无限循环，只能存一个最接近的近似值。`3.14` 在二进制里就近取到了 `3.140000104904175` 这个值。println 把它按完整精度打出来，误差就露出来了。

这个误差平时几千万分之一，日常计算无感。但**比较两个 Float 是否相等要小心**：`0.1 + 0.2 == 0.3` 在几乎所有语言里都是 `false`，因为两边都是近似值。需要精确比较时，先想想能不能用整数（比如钱用"分"而不是"元"来存）。

## 四、动手练习（12 分钟）

**练习 1（动手）**：在 `main` 里加一行，猜猜 `inferred` 是什么类型，然后打印：

```moonbit
let inferred = 2026
println("inferred = \{inferred}")
```

输出是 `inferred = 2026`，编译器推断它是 `Int`。再把 `2026` 改成 `2026.5`，这次它会推断成 `Float`。同一个名字，值不同类型就不同，推断是跟着字面量走的。

**练习 2（故意犯错）**：把 `letter: Char = 'M'` 的双引号换成单引号（`letter: Char = "M"`），运行看报错。错误信息会告诉你类型对不上：String 不能放进 Char 的位置。读完报错，改回来。

**练习 3（思考）**：`let ok: Bool = 1` 能通过吗？在 MoonBit 里 `1` 是 Int，不是 Bool。很多语言允许数字当布尔用（0 是假、非 0 是真），MoonBit 不允许，必须写 `true` 或 `false`。想想这种"严格"的好处。

## 今日小结

- 五种基本类型：`Int` / `Float` / `String` / `Bool` / `Char`
- 字符串用双引号，字符用单引号，写反了编译器会报错
- 类型可以显式标注（`: Int`），也可以靠字面量推断
- Float 打印完整精度时可能带误差尾巴，`3.14` → `3.140000104904175` 是正常的
- Float 相等比较要小心，需要精确时优先用整数
