# 100 Days of MoonBit

按天推进的学习路线：每天 25 分钟，学一个主题、跑一个示例、做一个练习。
适合需要节奏感、想打卡坚持的人。想按主题查内容？去 [MoonBit by Example](../examples/README.md)。

## 双入口说明

MoonHive 学习库提供两种进入方式，**同一批示例，两种学法**：

| 入口 | 组织方式 | 适合谁 |
|---|---|---|
| [By Example](../examples/README.md) | 按主题查：想学 match 直接打开 match 示例 | 有明确目标、查字典式学习 |
| **100 Days（本目录）** | 按天走：Day 1 → Day 25 顺着学 | 需要节奏感、打卡式坚持 |

## 怎么用

1. 每天看一篇 `DayNN.md`（约 25 分钟）
2. 按步骤读对应示例、自己运行一遍
3. 做末尾的动手练习
4. 在打卡区写下完成情况——问题记下来，比"看懂了"更有用
